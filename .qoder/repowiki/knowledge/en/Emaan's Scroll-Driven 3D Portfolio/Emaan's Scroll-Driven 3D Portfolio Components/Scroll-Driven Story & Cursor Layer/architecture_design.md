The module composes four React client components that sit above the 3D scene to deliver a scroll-narrated experience. `SmoothScroll.jsx` is the root wrapper: it instantiates a Lenis instance on mount, bridges its `raf` loop into `gsap.ticker`, and forwards children so all scroll-triggered animations share one smooth scroll context. `ScrollStory.jsx` defines the top-level `<section>` with a sticky container; it fades out an intro header via GSAP ScrollTrigger as the user scrolls, then renders `StoryContent` (HTML overlays) and `ThreeWorkspace` (the actual 3D scene) back-to-back so they animate in sync. `StoryContent.jsx` drives the narrative by mapping a `PANELS` config array (`AboutSection` → `ContactSection`) onto refs and animating each panel in/out with paired `fromTo`/`to` ScrollTriggers keyed by percentage-based start/end positions relative to the shared `storyRef`. `ScrollProgress.jsx` is a lightweight standalone progress bar driven by a passive `scroll` listener. `Cursor.jsx` is an independent canvas-based particle system that spawns colored code symbols behind the mouse using `requestAnimationFrame`; it uses `useSyncExternalStore` to detect touch devices and renders nothing on touch. Dependency direction is strictly downward: this layer depends on `@/components/three/ThreeWorkspace` and `./sections/*` but no component here imports from the 3D scene, keeping the scroll narrative decoupled from the WebGL implementation.
