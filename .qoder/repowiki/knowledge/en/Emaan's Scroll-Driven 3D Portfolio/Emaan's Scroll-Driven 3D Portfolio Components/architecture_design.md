The module composes two cooperating layers around a shared scroll timeline: `three/` renders the persistent 3D workspace (Room, Avatar, Cat, Desk, Chair, WhimsyWorld) via React Three Fiber, while `sections/` provides one React component per portfolio topic that drives camera moves, object animations, and overlay content through GSAP ScrollTrigger. The top-level files (`Cursor.jsx`, `ScrollProgress.jsx`, `SmoothScroll.jsx`, `ScrollStory.jsx`, `StoryContent.jsx`) wire Lenis smooth scrolling to the same timeline so every section animates in sync with the 3D scene. Sections communicate with the 3D layer indirectly by advancing the shared scroll position rather than calling into Three.js directly, keeping the 3D scene decoupled from page layout concerns.
