The root project composes two layers: `app_pages` provides Next.js App Router entry points (root layout, home page, static detail routes) that import and mount the 3D/scroll runtime defined in the sibling `components` directory. `components` owns all Three.js + R3F scene state, GSAP timelines, Lenis smooth scrolling, custom cursor, and per-section UI panels; it exposes them as client components with props/state so pages remain thin shells without routing knowledge. Cross-child communication is purely component-based — no shared modules or path aliases are used, relying on relative imports between `app/` and `components/`. Root config files (`next.config.mjs`, `postcss.config.mjs`, `eslint.config.mjs`, `jsconfig.json`) provide a minimal Next.js 16 / Tailwind v4 / ESLint 9 baseline with no custom path aliases.
