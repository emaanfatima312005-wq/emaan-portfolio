Built on Next.js App Router conventions under `app/`. `layout.js` is the server-side root layout: it loads Geist Sans/Mono via `next/font/google`, exports global metadata (title, description, OpenGraph), and wraps every route in `<SmoothScroll>` plus a `<Cursor>` component from `@/components`, establishing shared chrome. `template.js` is a sibling client-side route template that wraps each page transition in a Framer Motion `motion.div` with fade/slide/scale enter-exit animations, providing consistent per-page motion without animating inside individual pages. `page.js` is the client-side home route (`"use client"`) that shows an animated loading screen for ~3.2 seconds before rendering `ScrollStory` and `ScrollProgress`, which drive the main scroll-driven narrative. `project/[slug]/page.js` is a dynamic route using `generateStaticParams` to pre-render one URL per item in `@/lib/data`, looking up the project by `params.slug` and rendering a detail view with features and contact info. Styling is centralized in `globals.css` (Tailwind-imported) and scoped to this app layer; no component-level CSS modules are used here.
