Built as a Next.js App Router client app. `app/layout.js` wraps the entire tree in `SmoothScroll` (Lenis) and a custom `Cursor`, while `app/page.js` renders a loading screen then delegates to `ScrollStory`. The 3D scene lives in `components/three/ThreeWorkspace.jsx`, which owns a single `<Canvas>` and composes `Room`, `Avatar`, `Desk`, `Chair`, `Cat`, and `WhimsyWorld` under shared lighting. A `ScrollCamera` component uses GSAP ScrollTrigger to drive a timeline that walks the avatar to the chair, frames her sitting, turns toward the monitor, zooms through it, and pulls back into the whimsical world; it also drives the `progress` state passed to child components so they can fade/scale based on scroll position. Overlay HTML panels are defined in `components/sections/*` and orchestrated by `StoryContent.jsx`, which maps each section to a `{start, end}` percentage range and animates opacity/y/scale via per-panel ScrollTriggers. All static content (profile, education, experience, projects, skills) is centralized in `lib/data.js` and consumed by sections and project detail routes (`app/project/[slug]/page.js`). Tailwind CSS v4 with PostCSS handles styling, and `next.config.mjs` configures the build.
