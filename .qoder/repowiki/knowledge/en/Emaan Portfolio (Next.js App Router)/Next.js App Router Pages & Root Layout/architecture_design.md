Built on Next.js App Router conventions under `app/`. `layout.js` is the root layout: it injects Google Fonts (Geist Sans/Mono via CSS variables), sets global metadata (title, description, OpenGraph), and wraps all children in `<SmoothScroll>` and `<Cursor>` components from `@/components`, establishing the shared chrome for every route. `template.js` is a client-side route template that wraps each page transition in a Framer Motion `motion.div` with fade/slide/scale enter-exit animations, providing consistent per-page motion. `page.js` is the client-side home route: it shows an animated loading screen for ~3.2 seconds then renders `ScrollStory`, which drives the main narrative experience. `project/[slug]/page.js` is a static-generated dynamic route using `generateStaticParams` to pre-render one page per project from `@/lib/data`; it looks up the project by `params.slug` and renders a detail view with features and contact info. Styling is centralized in `globals.css` (Tailwind-imported) and scoped to this app layer; no component-level CSS modules are used here.
