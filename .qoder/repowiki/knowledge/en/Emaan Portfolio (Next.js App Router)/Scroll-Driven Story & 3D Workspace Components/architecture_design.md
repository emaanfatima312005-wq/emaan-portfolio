The module is organized as a flat collection of client-side React components plus two sub-packages. `ScrollStory.jsx` is the top-level entry that mounts a sticky container holding three layers: an intro text layer, `StoryContent` (overlay panels), and `ThreeWorkspace` (the 3D scene). `StoryContent.jsx` declares a `PANELS` config array mapping each section (`AboutSection`, `ProjectsSection`, `SkillsSection`, `ExperienceSection`, `EducationSection`, `ContactSection`) to its visibility window via GSAP `start`/`end` percentages, driving fade/slide transitions through `gsap.fromTo` + `ScrollTrigger`. The `sections/` directory contains one presentational component per panel, all consuming data from `@/lib/data` and styling themselves via CSS classes like `story-panel` / `experience-card`. The `three/` sub-package builds a single cohesive 3D scene around `ThreeWorkspace.jsx`, which sets up a `<Canvas>` and composes `Room`, `Desk`, `Chair`, `Cat`, `Avatar`, and `WhimsyWorld`; `ScrollCamera` uses `useFrame` + GSAP timelines bound to the same `storyRef` to animate camera position and avatar movement in lockstep with page scroll. `SmoothScroll.jsx` wraps the app with Lenis for smooth scrolling and bridges Lenis's scroll events into GSAP's `ScrollTrigger.update`. `Cursor.jsx` is a standalone custom cursor that detects touch devices via `useSyncExternalStore` and renders a dot + ring driven by `requestAnimationFrame`. All components are marked `'use client'` because they rely on browser APIs (window, matchMedia, requestAnimationFrame) and GSAP.
