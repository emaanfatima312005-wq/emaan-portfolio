The project is a single Next.js application whose runtime entry points live in `app/` (pages, root layout, global styles) and whose UI building blocks live in `components/`. The root `package.json` declares all shared dependencies (Next.js 16, React 19, GSAP, Framer Motion, Lenis, Three.js ecosystem) so both children consume the same animation and 3D stacks. `next.config.mjs` is left minimal, letting the App Router drive routing while `eslint.config.mjs` applies the Next Vitals ruleset across the whole repo. There is no cross-child API layer — pages import components directly, and the only wiring happens at the app level via the root layout and global CSS.
